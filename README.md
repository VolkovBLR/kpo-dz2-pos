# ПОС — преподавательская оценка студентов

Приложение позволяет завести студентов и рубрикатор, выставить оценки с проверкой инвариантов, рассчитать итог по весам и выгрузить итоги в CSV.

## Запуск

```bash
dotnet build Pos.slnx
dotnet test Pos.slnx
dotnet run --project src/Pos.Console
```

## DDD и ubiquitous language

- **Student** и **Criterion** — сущности с идентификаторами.
- **Evaluation** — сущность-факт выставленной оценки.
- **Score** — value object: хранит балл вместе с максимумом и не позволяет создать значение вне диапазона.
- **Repository** — порты `IStudentRepository`, `ICriterionRepository`, `IEvaluationRepository`; домен не знает способ хранения.
- **Domain Service** — `FinalScoreDomainService`, который считает итог из текущих критериев и оценок.
- Инварианты защищены в домене: балл находится в `[0, maximum]`, оценка создаётся только для существующих студента и критерия, итог не хранится отдельной цифрой.

## Архитектура

Выбрана учебная **Ports and Adapters (Hexagonal)**:

```text
Pos.Console (composition root, UI, DI)
        ↓
Pos.Infrastructure (in-memory repositories, CSV adapter)
        ↓
Pos.Application (use-case facade, ports)
        ↓
Pos.Domain (entities, value object, invariants, domain service)
```

Зависимости направлены внутрь: инфраструктура реализует порты приложения/домена, а консоль собирает граф зависимостей через `Microsoft.Extensions.DependencyInjection`.

## GoF-паттерны

1. **Factory (порождающий)** — `EvaluationFactory` создаёт оценку только после проверки максимума критерия; единая точка создания не даёт обойти инвариант.
2. **Facade (структурный)** — `PosApplicationFacade` предоставляет консоли понятные сценарии и скрывает координацию репозиториев и domain service.
3. **Strategy (поведенческий)** — `IFinalScoreStrategy` позволяет менять правило расчёта итога без изменения сущностей и сценариев; сейчас используется `WeightedFinalScoreStrategy`.

## Сквозной сценарий

Добавьте студента, например `Иван Петров`; добавьте критерии `Код` (10, вес 2) и `Защита` (5, вес 1); выставьте оценки; откройте «Итоги» и выберите экспорт. Некорректный балл или неизвестный критерий будет отклонён с понятным сообщением.

## Роль инструментов ИИ

Инструменты ИИ использовались как вспомогательное средство для разбора формулировок задания и проверки вариантов реализации. Ответственность за архитектуру, инварианты, код и результаты тестов остаётся у автора проекта.
